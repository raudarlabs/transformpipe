## Was übernommen wird

Um einen Confluence-Export in Markdown umzuwandeln, wird jede `.html`-Datei in der .zip gelesen, die der HTML-Export eines Space liefert. Standardmäßig wird der Space zu **einem Ordner mit Seiten**: ein Markdown-Dokument pro Seite, ein Unterordner pro Abschnitt, und die Seite des Abschnitts selbst steht darin an erster Stelle. Mit der Option **Einem Dokument** werden die Seiten stattdessen zu einer einzigen Datei zusammengeführt.

| Im Export | Im Markdown |
| --- | --- |
| Der Titel, geschrieben `Space : Seite` | `# Seite`, ohne den Namen des Space |
| Die Brotkrumen-Navigation | Der Ordner, in dem die Seite abgelegt wird |
| Überschriften, Listen, fett, kursiv | Dasselbe in Markdown |
| Eine Tabelle | Eine Markdown-Tabelle, die erste Zeile als Kopfzeile |
| Das Inhaltsverzeichnis-Makro, ein Link auf eine Überschrift | Ein Link auf den Slug der Überschrift im GitHub-Stil |
| Ein Link auf eine andere Seite | Ein Link auf diese Seite, im Ordner mit Seiten |
| Ein Bild unter `attachments/` | In die Seite eingebettet, große Bilddateien zuvor auf höchstens 1.600 Pixel an der langen Seite verkleinert |
| Ein Link auf eine Webadresse | Bleibt ein Link |

## Was zurückbleibt

- **Makros als Makros.** Keines hat eine eigene Regel: Jedes kommt als das HTML an, zu dem der Export es gerendert hat. Ein Info-Bereich wird also zu seinen Absätzen, ohne den Bereich.
- **Verbundene Zellen.** Der Text landet in der ersten Zelle, die die verbundene Zelle abdeckte, und unter einer nach unten verbundenen Zelle rückt die Zeile nach links. Eine Zelle mit mehreren Absätzen oder einer Liste wird auf eine Zeile zusammengezogen.
- **Anhänge, die keine Bilder sind.** Ein PDF wird nicht mitgenommen; im Ordner mit Seiten wird sein Link deshalb zu seinem Namen, ebenso Links auf Confluence-eigene Ansichten.
- **Bilder jenseits des Kontingents.** Im Ordner mit Seiten darf jede Seite knapp 4 MB an Bildern tragen, keines über 1 MB in kodierter Form; ein Bild, das nicht mehr passt, wird zu seinem Alt-Text oder Dateinamen in Kursivschrift. Ein einzelnes Dokument teilt sich 2 MB, und ein Bild darüber hinaus behält seinen Pfad unter `attachments/`.

## Ein Beispiel

Ein Space-Export, in dem die Seite „Deploy checklist“ unter „Runbooks“ ein Inhaltsverzeichnis-Makro, eine Überschrift, eine Tabelle, einen Link auf die Seite „Rollback“, ein verlinktes `runbook.pdf` und einen Screenshot enthält. Als Ordner mit Seiten, heruntergeladen als .zip, wird daraus `Engineering/Runbooks/Deploy checklist.md` (Bilddaten gekürzt, Seitenrahmen weggelassen):

```markdown
# Deploy checklist

- [Before you deploy](#before-you-deploy)

## Before you deploy

| Step | Owner |
| --- | --- |
| Tag the release | Ops |
| Announce the freeze | Release lead |

If it fails, follow [Rollback](Rollback.md). The full runbook is runbook.pdf.

![Pipeline](data:image/png;base64,iVBORw0KGgo…)
```

Der Eintrag im Inhaltsverzeichnis zeigte auf Confluences eigene ID `Deploychecklist-Beforeyoudeploy` und springt jetzt über den Slug. Als ein Dokument wäre die Seite ein Abschnitt unter einer Liste `# Contents` mit den Seitentiteln.

## Grenzen

Die .zip darf bis zu 250 MB groß sein; entpackt werden nur die Seiten und die Bilder, und eine .zip ohne `.html`-Dateien wird abgelehnt. Die Umwandlung läuft in Ihrem Browser: Ohne Anmeldung wird nichts hochgeladen, und angemeldet gelangt nichts in Ihr Konto, bevor Sie speichern. Eine gespeicherte Seite darf bis zu 4 MB groß sein.

Die Seiten werden nach Dateinamen geordnet, `index.html` zuerst, nicht nach dem Seitenbaum von Confluence. Nichts sucht den eigentlichen Seiteninhalt heraus: Außer der Brotkrumen-Navigation kommt der Seitenrahmen als Text mit, etwa eine Überschrift, die den Namen des Space wiederholt, eine Autorenzeile oder eine Zeile „Document generated by Confluence“. Prüfen Sie Codeblöcke: Ein eingezäunter Codeblock entsteht nur dort, wo das HTML `<code>` innerhalb von `<pre>` enthält; ein bloßes `<pre>` kommt als einfache Zeilen an. Häkchen werden nur aus HTML-Kontrollkästchen gelesen, für die Aufgabenlisten von Confluence gibt es keine Regel.

## Fragen

### Ist das eine Confluence-App oder ein Plugin?

Nein. In Confluence wird nichts installiert, und nichts hier verbindet sich damit: Sie exportieren den Space als HTML und legen die .zip hier ab. [Die kostenlosen Möglichkeiten im Vergleich](/blog/free-confluence-to-markdown-converter) behandelt auch die Apps aus dem Marketplace.

### Funktioniert das mit Exporten aus Confluence Cloud und Data Center?

Für keines von beiden gibt es einen eigenen Weg: Der Konverter liest aus jedem HTML-Export dasselbe – den `<title>` jeder Seite, die Brotkrumen-Navigation, die IDs der Überschriften und den Dateinamen. So oder so nimmt diese Seite die .zip des HTML-Exports an und keine andere Datei.

### Kann ich eine einzelne Confluence-Seite in Markdown umwandeln?

Ja, sofern sie als HTML in einer .zip vorliegt. Gelesen wird jede `.html`-Datei im Archiv, eine einzelne Seite wird also genauso umgewandelt wie sechshundert.

### Bekomme ich statt Markdown auch HTML?

Wählen Sie die Option **Einem Dokument**: Das Download-Menü des Ergebnisses bietet neben Markdown auch HTML, Word und reinen Text an. Ein Ordner mit Seiten wird nur als Markdown heruntergeladen.

### Funktionieren die Links zwischen den Seiten weiter?

Im Ordner mit Seiten ja: Jeder Link zeigt auf das gespeicherte Dokument in Ihrem Konto oder auf die Datei der verlinkten Seite in der heruntergeladenen .zip. In einem einzigen Dokument behalten die Links die Dateinamen des Exports, die außerhalb davon ins Leere führen.
