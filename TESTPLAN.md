# Тест-план TransformPipe — живая проверка

**Составлен 1 октября 2026.** Проверяем всё, что человек может сделать руками: сайт, аккаунт, шеринг,
API, MCP в настоящих ассистентах, CLI, GitHub Action, вебхуки и расширение. Автопроверки
(`mcp:check`, `share:check` и остальные) гоняют контракт на сервере, но не видят ни интерфейс, ни
настоящих клиентов, ни почту, ни телефон — это и есть то, что здесь.

## Как пользоваться

- **Среда — прод**, `https://transformpipe.com`. Локалка (`127.0.0.1:5180`) только для повторения бага.
- **Отметки**: ✅ работает · ❌ сломано · ⚠️ работает, но плохо · ⏭ не проверяли. Рядом —
  ссылка на скрин или короткое описание. Каждый пункт имеет ID (`SHR-07`), по нему и говорим о
  баге.
- **Приоритет**: **P0** — блокирует запуск или ревью в каталогах; **P1** — заметно пользователю;
  **P2** — мелочь.
- **Тестовые документы** называем `zz-…`, чтобы потом найти и удалить одним поиском.

## 6. Публичный API — P0

Ключ создаём в меню аккаунта (A): показан один раз, дальше только маска. Все вызовы —
`Authorization: Bearer tp_live_…`.

| ID | Запрос | Случаи |
| --- | --- | --- |
| API-01 | `POST /api/v1/documents` с телом-файлом | `.md` → 201; `?kind=word-to-markdown` с `.docx`; `?name=`; неизвестный `kind` → 400 |
| API-02 | `POST …?share=link` / `?share=people` | ссылка в ответе; неподтверждённый аккаунт + `link` → 403 с объяснением |
| API-03 | `POST …?share=link&expires_at=…` | срок в ответе; `expires_at` без `share` → 400 |
| API-04 | `POST …?replaces=<id>` | новая версия в цепочке; чужой id → 404 |
| API-05 | `GET /api/v1/documents` и `?q=` | список; поиск по содержимому |

## Что уже известно

- **ChatGPT**: удаление подтверждается дважды — ChatGPT спрашивает сам, а наш инструмент ещё
  требует `confirm`, поэтому первая попытка может ответить «blocked by safety checks», пока
  человек не скажет «да» в чате. Поведение безопасное; решить, упрощать ли.
- **ChatGPT**: карточки кэшируются. После правки карточки — Settings → Plugins → TP →
  Refresh tools. Адреса карточек теперь меняются вместе с содержимым, так что обновления хватает.
- **ChatGPT**: предупреждение «Add an outputSchema» — рекомендация, не блокирует ревью.
- **Cursor**: не подключается, возвращает на свою схему адреса, которую сервер не принимает.
